# 🚀 Peer-to-Peer Learning Platform

> **A decentralized AI-powered learning platform that transforms YouTube videos into an interactive knowledge base using Peer-to-Peer networking, Natural Language Processing (NLP), and Semantic Search.**

---

## 📖 Overview

The **Peer-to-Peer Learning Platform** enables users to learn from educational YouTube videos more efficiently by converting video content into an intelligent, searchable knowledge base.

Instead of watching an entire video to find specific information, the platform:

* 🎥 Extracts the YouTube video transcript.
* 📝 Generates an AI-powered summary.
* 🧠 Converts the transcript into semantic embeddings.
* 📚 Stores the knowledge in a vector database.
* ❓ Allows peers in the network to ask questions and receive relevant answers instantly.

This project combines **Peer-to-Peer (P2P) Networking**, **Natural Language Processing**, and **Semantic Search** to create a decentralized learning system.

---

## ✨ Features

* 🔗 Peer-to-Peer communication between nodes

* 📝 AI-based text summarization

## ▶️ Running the Project

### Start Node A (Knowledge Source)

```bash
python p2p_learning_platform.py
```

Select:

```text
A
```

### Start Node B (Questioner)

Open another terminal and run:

```bash
python p2p_learning_platform.py
```

Select:

```text
B
```

Ask your questions interactively and receive answers generated from the processed YouTube knowledge base.
